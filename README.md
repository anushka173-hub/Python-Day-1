This project contains solutions for Day 1 Python Foundations (Assignment A, Assignment B, and Hard Scenario).

## Key Decisions & Implementation (Hard Scenario)
- **Empty Employee List:** If the employee list is empty, the average salary function returns `0` to prevent division-by-zero errors.
- **None Salaries:** Employees with a `None` salary value are safely skipped during calculations.
